# vivo 双击电源键打开相机

2.0 正式版采用用户已接受的 1.0-standalone.13 功能基线。本次仅更新版本元数据与便携目录入口，不更改配对、授权、自动恢复或按键监听行为。

无需 root，适用于 vivo X300 / OriginOS 6（Android 16）。最低 Android 12，arm64-v8a。

## 本版修复

固定 libadb 3.1.1 把 mDNS 发现超时也抛成 InterruptedException，旧控制器会提前按中断退出，跳过后续重试。本版区分该精确错误与真正的取消；保留有限重试，不增加闲置轮询。助手处理和编译设置先回到 .11，保留许可去重。已确认该代码缺陷；用户两种重启和启停场景仍需真机复验。

## 下载与使用

在 [Releases](../../releases/latest) 下载 `VivoCamera-Controller-2.0.apk`。APK 约 0.45 MB，使用原签名，可覆盖升级并保留配对。

1. 将系统“双击电源键”设置为“无功能”，关闭其他按键拦截。
2. 首次使用连接 Wi-Fi、开启开发者选项，在 App 的“设置 → 首次配对”按提示完成本机配对。
3. 点击“启动”。确认运行后会保留 USB 调试、关闭无线调试，显示一秒后关闭界面；无需插 USB 线。
4. 若需开机自动启动，在设置中保留自动启动开关、开启恢复助手无障碍权限，并在系统中允许应用自启动。重启后首次解锁再联网即可等待恢复，晚些连接 Wi-Fi 也支持。

旧版若已被系统关闭恢复助手，升级后请重新开启一次；无需清除数据或重新配对。

## 连续打开与状态

首页保留状态、启动、停止、关闭控制界面和设置；手动配对、连接端口、实时检查和记录收进“故障排查”。

再次打开 App 只读取本次开机的启动记录，不自动重连调试，不触发网络授权。历史记录显示“已启动”，不作为实时健康检测；在“设置 → 故障排查 → 检查实时状态”查询通过后才显示“正在运行”。重启会使旧启动记录失效，确认停止后显示“已停止”。仅查看历史记录时不会自动退出。

助手权限和监听器状态分别处理。手动停止会暂停本次开机自动恢复；停止失败不会丢失此前的启动记录。

## 授权与省电

授权助手的扫描和事件合并恢复 .11 行为；授权会话先于身份加载开启。不承诺真机具体耗时。助手待机保留系统设置和 SystemUI 的最小窗口切换事件订阅，避免将无障碍配置清零；没有任务时直接返回，不读取窗口、不点击、不定时扫描。配对和授权期间才临时接收内容变化并检查系统窗口。

已连接的系统无障碍助手会在联网、解锁和服务连接事件后直接发起有限次恢复；系统持久化 Wi-Fi 任务作为后备，同一连接最多三次尝试。两条路径共用单一执行权，网络变化不替换正在执行的同 ID 任务。没有新增定时轮询、常驻前台通知服务或唤醒锁。网络授权只取消“始终允许”并确认本次“允许”，不自动批准其他弹窗；锁屏时等待解锁。启动或实时检查成功后关闭无线调试、保留 USB 调试。

控制界面关闭后独立监听器继续运行。监听器以 shell 权限只读物理按键，不独占输入，不吞按键，不开放网络端口。手机重启后需要重新启动，由自动恢复或手动完成。

## 源码与构建

`src/` 是 1.0 监听核心，`tests/` 是核心测试；`experiments/standalone-controller/` 是控制器。

Release 的 `VivoCamera-Controller-source-public.zip` 包含完整源码、固定第三方 JAR/native 输入、许可证和 LGPL 对应源码/重新链接说明。仓库不提交依赖二进制，克隆后可从源码包取得 `libs/`、`native/` 和 `assets/vivo-camera.jar`。

在控制器目录使用 PowerShell 7、JDK 17、Android SDK platform android-37.0、build-tools 36.0.0：

```powershell
.\Build-Standalone.ps1 -JdkPath 'C:\Tools\jdk-17' -SdkPath 'C:\Android\Sdk' -WorkRoot 'C:\BuildCache\vivo'
```

产物位于 `<WorkRoot>/dist/`。构建只使用已有依赖、不联网下载；自行构建使用新开发密钥，无法覆盖官方签名版本。R8 仅裁剪未使用代码，不混淆、不进行代码优化，恢复 .11 的编译边界。APK 中逐字节相同的许可全文合并为一份，以原名短引用及 PACKAGED_LICENSE_MAP.json 对应；完整源码包保留全部许可原文。共享环境入口保留在 `Build-Standalone-Local.ps1`，独立构建无需该共享环境。

电脑方式可使用 `VivoCamera-Core-1.0.zip` 及自备 platform-tools：

```powershell
.\Start-VivoCamera.ps1 -AdbPath 'C:\Android\platform-tools\adb.exe'
.\Stop-VivoCamera.ps1 -AdbPath 'C:\Android\platform-tools\adb.exe'
```

多设备时加 `-Serial 'DEVICE_SERIAL'`。默认双击间隔 350 ms，第二次松开后等待 150 ms；支持 `-DoubleMs 150–600`、`-DelayMs 0–1000` 和 `-DryRun`。

## 自动启动边界

目标是在首次解锁、连上 Wi-Fi 后自动完成授权与启动，无需进入 App。系统仍需允许自启动和后台运行，恢复助手必须保持开启。强行停止、系统冻结后台、未解锁或调试配对被撤销时不能保证自动完成。失败时可在故障排查查看恢复阶段，不记录网络名、配对码或异常原文。
